# Feature requests

Open ideas and design notes. Not a commitment to build — a place to park context so we can revisit later.

**Public repo:** keep FRs free of private infra (hostnames, internal service names, personal domains, vault paths, deploy tooling specifics). Product decisions and public stack choices are fine; operational detail belongs outside this repository.

## How to add one

1. Copy `_template.md` → `FR-NNN-short-slug.md` (next free number).
2. Fill status, problem, options, decision (if any).
3. Link it from the table below.
